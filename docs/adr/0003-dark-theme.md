# 黑夜模式切換

狀態：已接受  
日期：2026-11-04

## 背景

應用目前只有日間配色，色彩寫在 `src/styles/variables.scss`。需要可切換的黑夜模式，且不要讓現有使用者第一次打開就變黑。

## 決定

- 側邊欄標題列放圖示按鈕：日間顯示月亮（切到黑夜），黑夜顯示太陽（切回日間）。任何頁都能切。
- 只有日間／黑夜兩種，不跟作業系統走。
- 第一次使用預設日間。選擇存在本機 `localStorage`（`bullet-journal-theme`），重新開啟仍是上次的模式。
- 用 CSS 變數換膚，掛在 `html[data-theme]`，讓 teleport 到 `body` 的選單、對話框一併跟著變。
- 備註便利貼在黑夜模式加深背景、維持原本色相，避免淺色色塊過亮。

## 後果

`src/utils/theme.ts` 負責讀寫與套用。`index.html` 在載入前先讀本機設定，避免先閃日間再變黑。
