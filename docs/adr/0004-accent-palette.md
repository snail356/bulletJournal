# 可選主色系

狀態：已接受  
日期：2026-11-04

## 背景

程式架主色寫死紫色（`--primary` 與衍生淺／深色）。黑夜模式已可切換，但色相不能換。任務標籤與狀態「進行中」也有紫色，那是資料顏色，與品牌主色不同。

## 決定

- 設定新增「外觀」分頁：主色色盤，以及與側邊欄同步的黑夜開關。側邊欄日月按鈕保留。
- 六種預設色盤：紫（預設）、藍、青、綠、橙、玫紅。點選立刻套用。不提供自訂色碼。
- 只改程式架（按鈕、選單亮點、開關、連結、瀏覽器 theme-color）。不改任務標籤、狀態顏色，也不改右下光球。
- 選擇存在本機 `localStorage`（`bullet-journal-accent`）。無效值回落紫色。

## 後果

`src/utils/accent.ts` 負責讀寫與套用 `html[data-accent]`。日間／黑夜的淺色與深色由各色盤在 CSS 裡配好。
